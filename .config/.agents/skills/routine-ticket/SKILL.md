# routine-ticket

Use this skill to make a markdown in a code block, title and description for the
user to copy into a routine ticket.

Example:

```
# Descriptive title for the task / ticket

Description of the issue, what have we observed happens or what is the problem
we want to solve and why.

MR: https://link-to-mr-if-we-created-one

## Solution implemented, if we did

What did we do and why did we do it that way. Any tradeoffs we considered?
Things we may want to look in the future?
```

And remember, some times it is better to say nothing. Be concise and specific.
